NetWolf Local Agent Setup

Level 2 connector for safe local FortiGate checks.

Safe default: the agent listens only on 127.0.0.1, starts in dry-run mode, and does not upload firewall output to the internet.

Download NetWolf Local Agent

Option 1: Local Agent

  1. Download netwolf-agent.zip.
  2. Extract the zip file.
  3. Open the extracted netwolf-agent folder.
  4. Double-click start-local-agent.bat.
  5. Go back to NetWolf Assistant and click Check Agent.

You should see:

NetWolf agent listening on http://127.0.0.1:5051
Command execution is OFF (dry-run only)

Option 2: MSP/NOC Jump Server

Run the same agent on an internal jump server behind VPN or LAN. Keep it private. Do not expose port 5051 to the public internet.

For production, place it behind internal HTTPS with authentication and logging.

What Stays Local

  • No Groq, Claude, OpenAI, Firebase, or other cloud API calls from the agent.
  • No device passwords or API tokens are stored by the agent.
  • Audit logs stay in the local logs folder.
  • The /logs viewer returns audit metadata only, not passwords, SSH keys, or command output.
  • Dry-run mode shows commands only; it does not connect to a firewall.

View Agent Logs

In NetWolf, open NetWolf Assistant → Level 2 Live Agent and click Agent Logs.

You can also open the local endpoint:

http://127.0.0.1:5051/logs

Enable Real Read-Only SSH Later

Only after dry-run is tested, edit config.json and change:

"enableCommandExecution": false

to:

"enableCommandExecution": true

Use a read-only FortiGate account and keep the agent inside the customer network or VPN.

Create SSH Key For Read-Only Access

If the FortiGate read-only account uses SSH key login, create the key on the engineer PC or jump server.

ssh-keygen -t ed25519 -f "%USERPROFILE%\.ssh\netwolf_fortigate_key" -C "netwolf-readonly"

This creates two files:

C:\Users\<user>\.ssh\netwolf_fortigate_key
C:\Users\<user>\.ssh\netwolf_fortigate_key.pub

Paste this private key path into NetWolf:

C:\Users\<user>\.ssh\netwolf_fortigate_key

Add the contents of the .pub file to the FortiGate read-only admin account:

config system admin
    edit "netwolf-readonly"
        set accprofile "read-only"
        set ssh-public-key1 "<contents of netwolf_fortigate_key.pub>"
    next
end

Keep the private key file private. Only the .pub file should be copied to the firewall.
